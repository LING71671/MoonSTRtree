[English](../en/DEVELOPMENT.md) | [中文说明](./DEVELOPMENT.md)

本文规范 MoonSTRtree 的低耦合分层架构、内存与遍历不变式、质量验收标准及面向申报的 10+ 原子提交路线图。

## 1. 低耦合分层架构设计

系统严格划分为单向依赖的解耦层次，每一层专注于单一职责，杜绝跨层耦合：

```text
+-------------------------------------------------------+
|                    应用与展示接入层                    |
|             (CLI 基准评测、WebAssembly 画布演示)       |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|                    空间查询引擎层                     |
|           (迭代栈 DFS 遍历、外包矩形空间剪枝)          |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|                    紧凑扁平存储层                     |
|          (多层原生连续数组、零 GC 空间排布模型)       |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|                   STR 批量构建算法层                  |
|         (双向切片排序、纯数学自底向上打包逻辑)        |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|                    空间几何基元层                     |
|         (Rect、坐标归一化、相交与点包含纯函数)        |
+-------------------------------------------------------+
```

### 模块职责与解耦边界

| 层次模块 | 源码文件 | 上游依赖 | 不变式与解耦隔离边界 |
| :--- | :--- | :--- | :--- |
| **几何基元 (Geometry)** | `geometry.mbt` | 无 | 纯数学无状态计算。完全不感知树结构、切片逻辑、存储模型与查询栈。 |
| **STR 构建器 (STR Builder)** | `str.mbt` | `geometry.mbt` | 纯打包启发式算法。只负责切片数量计算、中心点坐标排序与节点聚合，不包含查询和渲染逻辑。 |
| **紧凑存储 (Packed Tree)** | `tree.mbt` | `geometry.mbt`, `str.mbt` | 连续扁平数组物理存储。构建后完全只读不可变，天然并发安全。 |
| **查询引擎 (Query Engine)** | `query.mbt` / `tree.mbt` | `geometry.mbt`, `tree.mbt` | 迭代式深度优先遍历。在连续数组上按偏移跳转剪枝，查询内层循环零临时对象分配。 |
| **诊断统计 (Diagnostics)** | `stats.mbt` | `tree.mbt` | 独立度量。计算树高、节点数、填充率等结构指标，不侵入核心热点检索代码。 |

## 2. 核心工程约束与不变式

1. **查询过程零额外堆分配（Zero GC Query）**：
   - 范围查询与点查询内层循环使用预分配的整数索引栈跟踪待访问节点。
   - 禁止在遍历过程中创建临时 Node 对象或包装切片，杜绝 WASM/Native 下的垃圾回收毛刺。
2. **彻底消除函数递归（Zero Recursion Overhead）**：
   - 遍历采用显式迭代栈实现 DFS，栈深度严格受限于 `树高 * 节点容量`，杜绝深树调用栈溢出风险。
3. **构建后完全只读不可变（Read-Only Immutability）**：
   - 索引构建完成后禁止任何写操作，多个并发查询可安全共享同一树实例。
4. **全场景边界稳健性（Edge Case Robustness）**：
   - 必须通过零面积点矩形、水平/垂直退化线段、大量重合矩形、负数浮点坐标及空数据集的完备测试。
5. **MoonBit 最新工具链语法合规**：
   - 严格采用现代化语法：`derive(Debug)`、`!expr`、`pub fn Type::meth`、`assert_eq`。
   - `moon check` 保持零错误、零警告。

## 3. 测试与验收标准

- **单元与边界测试**：`intersects`、`contains_point`、`union`、`is_valid` 均具备独立白盒测试。
- **暴力扫描等价性验证**：在 1k、10k、100k 规模下，所有范围查询结果必须与 $O(N)$ 暴力全量扫描交叉比对，保证 100% 结果一致。
- **基准可复现性**：公开测试数据分布（均匀分布、高密度聚集、重叠与退化），测量真实构建吞吐与检索延迟。

## 4. 申报合规的 10+ 原子提交路线图

为满足黑客松申报要求的“不少于 10 个有效 commits，无无意义拆分”，后续开发将严格按照如下有实质代码增量的原子步骤提交：

1. `chore`: 初始化 MoonBit 项目脚手架、模块配置与 `.gitignore`（已完成）。
2. `docs`: 建立产品规格与低耦合架构指南（已完成）。
3. `docs`: 补充正式接口规范契约与品牌资产（已完成）。
4. `feat(geometry)`: 实现 2D `Rect` 几何基元与坐标自动归一化。
5. `test(geometry)`: 补充 `Rect` 相交、包含与退化几何白盒单元测试。
6. `feat(str)`: 实现 Sort-Tile-Recursive 双向切片计算与空间排序算法。
7. `feat(tree)`: 实现多层连续扁平数组物理存储与自底向上 MBR 打包。
8. `feat(query)`: 实现基于预分配迭代栈的 DFS 范围相交与点包含查询。
9. `feat(stats)`: 实现树高、节点数与空间填充率诊断指标。
10. `test(tree)`: 增加万级随机数据比对与暴力扫描一致性验证套件。
11. `perf(benchmark)`: 交付 1k、10k、100k 规模可复现基准评测程序。
12. `chore`: 完善模块导出、发布打包与接口契约校验。
