## 0.2.0 — 2026-10-12

### 核心库

- 按职责组织根入口、公开 API、核心几何／打包／索引／统计、领域扩展、数据生成与浏览器桥接。
- 二维索引直接构建 SoA 存储，在 STR 页边界分区；范围查询可整段复制完全包含的叶子区间。
- 修复数值溢出、中点与轨迹距离计算，增加安全存储恢复，并让紧凑 DBSCAN 正确处理稀疏及重复编号。
- 四维节点保存明确编号和层级，重合内部包围盒不再错误连接层级；标准 O(n log n) 排序替代平方复杂度循环。
- 近邻候选使用有界最大堆，结束时统一排序。完整距离回归覆盖二维、带过滤的三维、等距对象、多种容量及超过输入数量的 k。

### 兼容性

根入口 API 名称继续保留。规范几何类型归属于核心几何包，索引适配器及存储内部字段设为私有；直接修改字段和导入内部包的代码需要迁移。不声明二进制兼容。

### 演示与证据

- 提供中英文真实二维查询与独立完整结果校验，以及三维高度查询和四维时间片。
- 配置切换自动重建，查询停止变化后自动测量。缓存对象背景层，拖动时不再逐帧重画所有对象；过期 Worker 操作取消，旧结果清除。
- 发布包含 10,944 场景的完整 Benchmark 快照，保留固定公共数据、原始样本、覆盖率、较慢场景及源码／编译器指纹。另有 2,592 场景近邻对照，本轮相对旧实现为 1.3747x，同时保留 144 个较慢场景；该对照中仍慢于 Flatbush。
- 用图像生成统一黑白品牌标志、favicon 和横向 README banner，保留生成来源。

### 分发

要求 moonc 0.10.14 或更新版本，保留 Apache-2.0 许可及依赖声明，CI 验证四个核心目标。MoonBit 包排除浏览器应用及跑分证据，这些内容仍保留在公开仓库和 Pages 网站。

执行过的检查与实测限制见[验证记录](VALIDATION.md)。内存与多维性能仍属于后续工作，不作为本版本性能声明。
