# 产品说明

[English](../../PRODUCT.md) | [中文](PRODUCT.md)

网站提供完整中英文切换，默认中文并保存语言选择；切换时保留当前查询和实测结果。文案采用连贯、具体的说明，不使用短句拼接式口号。中文正文与标题自托管 Noto Sans SC，英文沿用 Barlow Condensed 与 Manrope。

MoonSTRtree 是 MoonBit 静态空间索引库，覆盖二维、三维、四维包围盒索引及几何、围栏、聚类、多边形和轨迹扩展。使用者包括游戏、地图/GIS 视口检索、图形和空间数据开发者；本轮网站主要面向比赛评委。

验收以可复现的查询结果、算法行为、跨目标运行及真实竞品测量为依据。输入须为有限坐标和非负 ID，精确几何有时需要候选筛选后的额外判断。计数查询仍有临时栈分配，缓冲恢复/导出为复制，不声明零 GC 或始终快于竞品。

用户选择代码先行的空间实验台，后续明确采用纯黑白视觉：大幅查询画布、可区分的查询与节点状态、实时对比。优先完成代码与有层次的目录优化，然后制作演示。根包是调用边界，文档中英文分文件维护。真实能力以源码和生成接口为准，合成数据与实测限制必须标识。

Benchmark 使用高效竞品适配器和独立完整参考，不隐藏失败或较慢场景。当前诊断覆盖 456 场景，标准配置声明 10,944 场景但尚未跑完；最终图表须依据完整原始报告。机场与跑道公开数据固定版本、核对哈希并公开排除规则。

三维高度查询和四维时间片查询提供真实核心的功能演示与完整结果导出；当前没有多维性能排名。真实应用案例属于后续规划，不作为已交付功能。仓库 topics 已设置，GitHub Pages 发布继续推进。
