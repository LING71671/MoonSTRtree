# MoonSTRtree 项目路线图 (Roadmap)

[English](../en/ROADMAP.md) | [中文说明](./ROADMAP.md)

本文档规范 MoonSTRtree 的研发阶段划分、里程碑交付成果以及未来演进规划。

---

## 项目愿景与目标

MoonSTRtree 旨在成为 MoonBit 生态中标准的高性能紧凑型二维空间索引库。核心追求：
1. **零运行时垃圾回收（Zero-GC）**：查询遍历过程绝不在堆上分配临时节点或对象。
2. **纯扁平连续内存（Packed Arrays）**：消除指针解引用开销，天然适配 WebAssembly、JavaScript 与 Native 目标。
3. **确定性与无外部依赖**：百分之百由 MoonBit 原生实现，构建结果只读不可变，天然具备线程安全性。

---

## 里程碑交付计划

### 第一阶段：基础设施与解耦几何基元 (v0.1.0) — 已完成

- **工程脚手架与规范约束**：
  - 完成 MoonBit 模块配置，建立中英双语文档架构。
  - 配置 Git 规范与 `.gitignore` 隐私数据过滤机制。
- **解耦 2D 几何包 (`src/geometry`)**：
  - 实现不可变 `Rect` 轴对齐包围矩形，内置坐标自动归一化保障（`min <= max`）。
  - 实现精确包围盒相交检测（`intersects`）、点包含检测（`contains_point`）、矩形包含（`contains_rect`）与最小外包矩形并集（`union`）。
  - 补充完备的白盒测试套件，全面覆盖零面积点矩形、退化线段及负数坐标边界。

---

### 第二阶段：STR 批量打包算法与连续存储 (v0.2.0) — 已完成

- **Sort-Tile-Recursive 分区引擎 (`src/str`)**：
  - 实现纯整数数学工具函数（`ceil_div`、`isqrt`、`ceil_sqrt`）。
  - 实现多切片垂直划分算法（$P = \lceil N/M \rceil, S = \lceil \sqrt{P} \rceil$）。
  - 实现双轴中心点递归排序：切片间按中心 X 排序，切片内按中心 Y 排序。
  - 自底向上递归聚合父级节点，动态收敛生成全局最小外包矩形。
- **紧凑扁平数组布局 (`src/tree`)**：
  - 彻底摒弃指针树，使用原生基础类型一维数组存储多层包围盒（`boxes_min_x/y/max_x/max_y`）。
  - 引入压缩稀疏行（CSR）拓扑偏移布局（`child_offset`、`child_count`、`child_indices`）。
  - 建立叶子节点与原始输入对象 ID 的直连映射数组（`item_ids`）。
- **迭代栈深度优先查询引擎 (`src/tree`)**：
  - 范围相交检索（`query`）：支持非相交子树空间快速剪枝。
  - 点拾取判定（`query_point`）：闭区间边界精确命中。
  - 纯迭代式整数栈遍历，彻底消除语言层函数调用栈溢出风险与遍历过程堆分配。

---

### 第三阶段：结构诊断、公开门面与全量对齐 (v0.3.0) — 进行中

- **结构诊断统计模块 (`src/stats`)**：
  - `TreeStats` 诊断指标：元素总量、树高、总节点数、叶子节点数、平均节点填充率。
  - 树结构几何一致性检验：递归验证父节点 MBR 严格包络所有子节点。
- **顶层统一公开门面 (`moon_strtree`)**：
  - 在根包统一导出 `Rect`、`StrTree`、`TreeStats`、`query` 与 `query_point`。
  - 对齐黑客松接口规范：`StrTree::build(items, node_capacity=16)`。
- **暴力验证等价性测试**：
  - 编写属性模糊测试（Fuzzing），生成 1,000 至 10,000 个随机矩形。
  - 对比 `StrTree::query` 与暴力 $O(N)$ 线性扫描结果，断言 100% 结果等价。

---

### 第四阶段：基准评测与 CLI 工具链 (v0.4.0) — 计划中

- **命令行驱动工具 (`cmd/main`)**：
  - 读取外部空间数据集并输出空间树拓扑诊断报告。
- **可复现基准评测套件 (Benchmark)**：
  - 涵盖均匀随机、高斯聚集、网格平铺及极端重叠四类分布模式。
  - 测量空间构建吞吐率（items/sec）与单次检索延迟（微秒级别）。
  - 审计 wasm32 与 native 目标下的峰值内存占用。

---

### 第五阶段：WebAssembly 交互式可视化演练场 (v0.5.0) — 计划中

- **浏览器 Canvas 交互页面**：
  - 编译为 WebAssembly 目标，通过 JavaScript 胶水层对接 HTML5 Canvas。
  - 实时绘制分层 MBR 轮廓线（不同树深度对应差异化色相）。
  - 支持鼠标实时拖拽查询窗口，毫秒级高亮相交图元并展示实时命中统计。

---

### 第六阶段：高维扩展与高级空间检索 (v1.0.0) — 远期规划

- **K 近邻检索 (k-NN Query)**：
  - 基于优先队列分支限界法实现最近邻空间对象搜索。
- **定距径向检索 (Radial Search)**：
  - 以指定点为圆心、半径 $R$ 为范围执行圆形相交检索。
- **三维空间包围盒扩展**：
  - 将 STR 算法推广至 3D 轴对齐包围盒（AABB Cuboid）。
