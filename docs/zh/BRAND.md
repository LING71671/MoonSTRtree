# 品牌素材

[English](../en/BRAND.md) | [中文](BRAND.md)

标志使用 M 形空间分区及嵌套查询开口，在近黑背景上呈现白色结构。网站导航和页脚将标志与可读项目名组合；README 使用横向 3:1 banner。

| 素材 | 规范路径 | 用途 |
| --- | --- | --- |
| 标志原图 | `playground/public/brand/mark-master.png` | 尺寸衍生版本的来源 |
| 网站标志 | `playground/public/brand/mark.png` | 256px 原图，显示为 44px／32px |
| 浏览器图标 | `playground/public/brand/favicon-{16,32}.png` | 明确提供小尺寸图标 |
| 触屏图标 | `playground/public/brand/apple-touch-icon.png` | 180px 保存网站图标 |
| 文档素材 | `docs/logo.jpg`、`docs/banner.jpg` | 标志及 2172×724 README 横幅 |

素材保持黑白，不拉伸、改色、添加光晕或额外底板，保留图像已有留白。界面控件继续采用中性状态与可读标签，不用品牌符号替代操作名称。

最终标志与横幅于 2026-10-12 使用 `image_gen.imagegen` 生成。每张图都嵌入原始提示词，并保存在[来源记录](../../playground/public/brand/provenance.json)。尺寸及格式转换保留生成图形；未采用的透明试稿不随项目发布。横幅矩形属于品牌插图，不是实时查询轨迹或跑分证据。
