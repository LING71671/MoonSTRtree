# 设计系统：MoonSTRtree playground

## Overview

**视觉北极星：“空间实验台”**

已实现的界面采用黑白仪器台、白色查询几何和清晰灰阶文字。绘图区、方形控件与分隔线构成主要语言，技术细节服从查询及其结果。

英文使用窄体标题建立层级，Manrope 承担英文阅读和操作。中文使用 Noto Sans SC，并有独立标题字号和行高。两种语言均用自然完整的说明解释查询、比较和限制。平面色阶与细线表达结构。此页面使用实时 Canvas 几何与自托管字体，没有随页面交付栅格插画。机器可读 token 以[英文主文件](../../DESIGN.md)为准；sidecar 中生成的色阶仅用于预览，不是新增产品 token。

本记录遵循[当前页面契约](../../.impeccable/surfaces/playground-src-app-tsx.md)中用户确认的纯黑白方向，覆盖此前铜色方案。视觉世界仍是以代码和真实几何为核心的空间实验台，候选 4，种子 d5e05efa。依据包括[样式](../../playground/src/style.css)、[应用](../../playground/src/App.tsx)、[绘图区](../../playground/src/components/SpatialCanvas.tsx)、[即时比较表](../../playground/src/components/BenchmarkLedger.tsx)、[Benchmark 报告](../../playground/src/components/BenchmarkReport.tsx)、[报告样式](../../playground/src/components/benchmark-report.css)、[多维实验](../../playground/src/components/VolumeExperiment.tsx)、[高度侧视图](../../playground/src/components/VolumeSideView.tsx)和[语言 Provider](../../playground/src/i18n/LocaleProvider.tsx)。当前 [.impeccable/review](../../.impeccable/review) 已包含宽度 1440 和 390 的完整中英文截图，以及可读的 Benchmark 和多维区截图。提供的完成复核证据记载字体已加载，页面主体没有横向溢出。

记录的复核状态为：**完整复核需修复：仅设计持久化；设计持久化限定复核结论：Resolved；剩余项 clear；disposition ship**。完整完成复核最初返回 `fix`，原因是设计记录过期；视觉、字体、材质、世界依据、契约和真实性检查在该次复核范围内通过。随后复核者 `/root/impeccable_finish_reviewer_retry` 对设计持久化修复返回 `Resolved`，该计分修复的剩余项为 clear，disposition 为 `ship`。这一最终限定结论确认文档修复完成；部署已另行验证，缺失的可选 QUALITY BAR 上限仍未认证。未提供对照作品、决策对照或 QUALITY BAR 卡片。真实应用案例仍属于未来工作。

运行检查点已发布至 [GitHub Pages 网站](https://ling71671.github.io/MoonSTRtree/)。提交 `d8ac98f5cc0c2a1fae7974b38dd01dafb48008f3` 已推送，[CI 运行](https://github.com/LING71671/MoonSTRtree/actions/runs/38184546848)和 [Pages 部署运行](https://github.com/LING71671/MoonSTRtree/actions/runs/38184577184)均成功完成。对实际发布网站的独立浏览器验证收到 HTTP 200，加载全部 10,944 个 Benchmark 场景，并显示 MoonSTRtree、Flatbush、RBush 和完整扫描的查询比值（0.77× / 1.00× / 0.73× / 0.062×）。真实四维查询返回 12 个匹配 ID；Benchmark 清单和第三方声明均返回 HTTP 200，没有警报。Pages 已配置为工作流部署并强制 HTTPS。这些运行观察记录发布状态和实际功能，不是新一轮视觉页面复核，也不认证可选质量上限。

**主要特征：**

- 哑光色阶与细分隔线。

- 移动端按绘图区、比较表顺序纵向排列。

## Colors

实现仅使用黑、白及中性灰。英文主文件中的值取自源码；sidecar 的灰阶预览色带不是新增产品 token。

### Primary

- **查询白：**查询轮廓和手柄、测量按钮、焦点、选区及原生控件强调。**操作悬停白：**启用主要按钮的灰白悬停状态。

### Neutral

- **页面黑：**页面。**仪器面板灰：**实验区和比较表。**深场灰：**查询画布。**控件灰：**原生选择框和数字字段。
- **阅读白：**正文。**柔和灰：**标签与元信息。**分隔灰：**边界和行分隔线。
- **保留白：**实线矩形审计边界。**排除灰：**虚线排除边界。**节点灰：**静态拓扑。**命中灰：**二维匹配对象；多维侧视图以白色填充命中对象。

**几何语义规则。** 白色表示查询，线型、线宽和标签区分矩形保留与排除状态。保留图例及实线/虚线差异。

## Typography

**英文标题字体：**自托管 Barlow Condensed（600），回退 sans-serif。

**英文正文字体：**自托管 Manrope Variable，默认字重（450），回退 sans-serif。

**中文字体：**自托管 Noto Sans SC Variable，覆盖中文标题、控件和正文，回退 sans-serif；标题字重（600）、行高（1.25）。

**标签与等宽字体：**英文控件使用 Manrope，中文控件使用 Noto Sans SC；两种语言的计时和坐标均使用 ui-monospace、monospace。

**性格：**紧凑英文标题与均衡中文标题形成相容层级；正文和表格式数值保持可读，完整解释允许自然换行。

### Hierarchy

- **展示标题：**英文桌面（64px），移动（44px），行高（1.02），最大宽度（23ch / 20ch）；中文桌面（48px），移动（34px），行高（1.25），最大宽度（18em）。两者字重（600）、字距（-0.02em）。
- **章节标题：**证据区英文桌面/移动（58px / 44px），中文（40px / 30px）；方法区英文（46px / 38px），中文（34px / 28px）。
- **小标题：**正文（16px / 650）使用对应语言字体；比较表标题英文桌面/移动（36px / 34px），中文（27px / 25px）；行名称（14px / 15px）。
- **正文：**方法文字（13px）、行高（1.65）、最大宽度（65ch）；引导文字（15px），移动（13px），最大宽度（65ch）；证据文字（14px），移动（13px）。
- **标签和数值：**控件标签（11px）；比较表辅助文字（10px），移动（11px）；计时（16px）等宽，显示四位小数。

**数值对齐规则。** 保留等宽与表格式数值、单位，以及构建观察值和查询计时的区别。

## Layout

居中容器最大宽度（1640px），桌面左右留白（44px），页头有细横线。实验区是连续面板：数据控件、绘图区及比较表、证据页脚。默认网格为弹性绘图区加固定比较表（326px），Canvas 高度（470px）。视口至少（1500px）时比较表（350px），Canvas（510px）。

视口不超过（1100px）时容器留白（24px），比较表（300px），Canvas（450px），结果说明纵向排列。不超过（760px）时留白（18px），数据控件两列，绘图区与比较表纵向排列，Canvas（370px），查询标签均匀分布，引导区和方法区改为单列。

能力表最小宽度（660px），放在横向滚动容器中；移动端仍能滚动查看竞品列。移动页头导航在（155px）内换行，隐藏页内证据链接，语言控件占单独一行并靠右。桌面证据区和方法区间距（72–76px），移动缩小为（48–52px），操作和数据行仍紧凑。运行说明桌面最大宽度（280px）并允许换行，移动端不设最大宽度；双语完整文案决定实际页面高度。

Benchmark 和多维区纵向内边距为（64px），在各自移动断点降为（40px）。Benchmark 六项筛选等宽排列；不超过（1100px）时为三列，不超过（760px）时为两列。图表采用固定名称列、弹性轨道和右对齐比值列，移动端缩小两端列宽。查询/构建切换按钮在移动端保持（24px）间距。Benchmark 表格最小宽度（720px），放在可聚焦的横向滚动区域；可见标题和解释留在滚动区域外，表格内部保留隐藏语义标题。多维视图在不超过（680px）时纵向排列；维度按钮保持（16px）间距和（44px）最小宽度。

## Elevation & Depth

实现没有盒阴影。深绘图区、略亮面板和字段、细边界及半透明坐标/加载遮罩表达层级。悬停改变颜色，不抬升控件。

**平面仪器规则。** 保留色阶分层与细线分隔；记录中的组件没有阴影或悬停位移。

## Shapes

面板和按钮采用方形。选择框和数字字段仅有（2px）圆角。面板和行分隔线（1px），活动下划线和焦点轮廓（2px），矩形角和线段端点使用（6px）方形手柄。Benchmark 用实心方块表示 MoonSTRtree，用空心圆表示竞品，并通过线型和可见数值辅助识别。圆形查询几何及图表标记具有功能语义；实现没有胶囊、标签芯片或圆角卡片体系。

## Components

### Buttons

主要按钮为白底深字，文字（13px / 750），内边距（12px 18px）；启用悬停使用灰白色。次要按钮透明底、结构边界与深灰色悬停；文字按钮为浅灰色下划线。最小高度（42px），禁用透明度（0.45），使用默认光标。

按钮、链接、输入、选择框和 Canvas 的键盘焦点使用白色（2px）轮廓及（5px）偏移。按钮颜色过渡（160ms ease-out）；减少动态效果偏好关闭此过渡和平滑滚动。

### Cards / Containers

实验区是带内部细线的单一容器，比较表共享面板底色，没有独立卡片网格。数据控件桌面内边距（20px 24px），移动（16px）；比较表（23px 22px），移动（22px 18px）。

### Inputs / Fields

原生选择框和数字字段使用深色填充、白字及灰色边界；悬停提亮边界，焦点沿用公共轮廓。复选框、范围输入和插入光标使用白色。绘图区局部控件更紧凑：高度（36px）、内边距（6px 8px）、字号（11px）；数据字段高度（42px）。标签位于上方或旁边。

草稿配置未应用时显示待应用状态和“Apply & build”。只有数据已构建、支持的答案一致、没有正在测量、没有待应用修改时才启用测量。初次打包显示遮罩，错误显示警报和重试。测量期间顶部按钮显示进度，完成比较后启用导出。

### Navigation

页头导航是（13px）普通文字，无胶囊容器；悬停白色，焦点沿用公共轮廓。中文和 EN 语言按钮最小高度（32px）、内边距（4px 9px）、字号（11px），选中显示浅灰文字和边界，悬停增加深灰色底。查询模式为具有按下状态的按钮：默认柔和文字，选中浅灰文字及白色下划线。移动端保留所有查询模式。

没有保存英文选择时默认中文，语言选择保存在 localStorage 的 `moon-strtree:locale`。切换更新界面文案、数字格式、页面语言/标题/描述及对应语言文档链接；存储可用时持久保存，受限时仍能当场切换。语言状态位于实验之上，因此切换保留数据、查询、草稿配置、树显示和已有测量。报告六项筛选与查询/构建选择也保持不变，多维实验的维度、查询和校验结果同样保留。两套字典均提供完整自然解释，而非压缩口号。

### Spatial field and bounds audit

Canvas 显示（0–1000）坐标范围。指针绘制或放置查询；方向键移动（10 单位），Shift 移动（40 单位），查询限制在场内。深度控件和对象开关控制结构显示。

矩形查询从编译后的 MoonBit 获得独立边界审计，在选定深度显示白色实线保留节点和灰色虚线拒绝节点。页脚显示数量，并明确它是不计时的边界审计，不是计时遍历遥测。点、最近邻、半径和线段仅显示静态节点拓扑，页脚说明此限制。半径和邻居参数仅在相应模式出现。

### Benchmark ledger

四行分别显示 MoonSTRtree、Flatbush、RBush 和线性扫描。Worker 在相同合成边界上执行真实索引；完整结果在计时区外对照独立扫描。最近邻比较完整距离序列，允许等距 ID 不同，同时要求编号有效且不重复。RBush 最近邻使用官方 rbush-knn 扩展并参与计时。Flatbush 半径和线段查询使用索引内部精确过滤；RBush 使用范围候选，再做精确过滤。

未计时使用横线，区分检查中、一致、不一致和不支持；不一致仍用明亮灰阶文字。浏览器即时测量预热十六次，分别校准各实现至约（12ms）批长，采集九批并轮换实现顺序，报告每次查询耗时中位数。完整结果在计时前后校验，校验不计入耗时。最快路径可能是竞品，MoonSTRtree 失利时保留结果。构建值是单独的单次输入适配与构建观察。导出包含原始样本、每套实现的查询次数、查询条件、版本与环境。比较表只测浏览器 JS 目标的二维查询，不建立通用速度、内存、原生、三维或四维性能承诺。

### Benchmark report and comparison plot

报告以有标签的对数比值图、细线数值表格和可展开测量方法延续仪器语言。六个原生选择框筛选数据类型、数据集、对象数、容量、种子及查询形状；文字按钮重置筛选。查询/构建按钮选择图表操作。初始选择全部声明场景。加载和校验和检查状态明确显示；下载或校验失败时出现警报、技术详情及重试，上方即时实验仍可用。

查询分数以 Flatbush（1×）为基准，计算 exp(mean(log(Flatbush 耗时 / 各实现耗时)))。选中场景等权，只有四套实现均具有正确且为正的实测值时进入共同计分场景。错误、不一致和未支持记录仍保留在选中数量和原始证据中。比值越大，图上越靠右；MoonSTRtree 的方块和竞品的空心圆用于识别实现，不暗示胜出。表格保留分数、场景耗时中位数、覆盖范围、错误和未支持数量。查询模式还显示按操作汇总的分数及 MoonSTRtree 逐场景差异；（5%）仅是实用分组，不表示统计显著性，P10–P90 是场景分布而非置信区间。构建分数按数据集/对象数/容量/种子去重，只比较三套索引；完整扫描无需构建。

当前[标准报告](../../playground/public/benchmarks/standard-2026-10-12.json)包含 10,944 个查询场景、96 个输入配置和 288 个构建配置，其中公开数据查询 684 个，失败数为零。测量来自干净提交 `f6972ca206a1010a7c6d58a12aa70bdaf503d388`，使用 MoonBit 编译器（0.10.14）、Node（22.22.1）和 V8。标准查询预热 64 次，分别校准至约（3ms）批长，采集九批轮换顺序的样本，计时前后与完整独立参考核对。构建先预热一次，再采集九次轮换索引顺序的样本。全部共同场景查询比值为 MoonSTRtree（0.7731×）、Flatbush（1×）、RBush（0.7283×）、完整扫描（0.06176×）；构建比值为 MoonSTRtree（0.4981×）、Flatbush（1×）、RBush（0.28182×）。这些是特定源码快照的实测结果，保留 MoonSTRtree 的失利，不是可复用视觉 token 或通用排名。

固定版本公开输入使用全部 86,231 个有效机场点和 15,557 个有效跑道端点包围盒；32,779 条缺少完整有效端点的跑道记录按公开规则排除。经纬度作为平面角度坐标，而非测地距离；种子仅重排完整有效数据，不筛选有利样本。测量方法展示设备、运行时、编译器、依赖版本、完成时间、测量提交及核心/测量器/原始文件 SHA-256。清单验证紧凑报告，下载 gzip 保留全部场景和样本。当前演示核心哈希不同时，报告明确提示版本差异并链接实测提交。因此后续四维 ID 修复不会悄然继承此前二维性能结论。三维和四维投影仍是独立的正确性演示。

### Volume experiment and side view

新增实验提供三维范围查询，使用可选高度区间；四维时间片查询则在该区间之外增加时间位置。独立 Worker 调用编译后的 MoonBit 三维/四维 API，并用完整排序命中 ID 数组对照独立穷举扫描。两平面显示同一批命中：可交互俯视图投影 X/Y，不可交互侧视图投影 X/高度，高度向上增加。白色查询轮廓和填充命中对象与灰色背景对象区分。投影不表示多维遍历遥测。

控件提供三维/四维、1,000/10,000 个合成对象、高度下限/上限，以及四维时间滑块。当前生成器固定种子 42、节点容量 16，坐标是合成无量纲单位。构建、检查、校验一致/不一致及错误重试状态明确显示。结果表预览前十个命中 ID 和高度边界，四维额外显示时间边界。仅校验通过后启用导出，包含全部命中 ID、完整三维/四维包围盒、查询、校验状态及版本信息。这是查询与正确性证据，不是多维性能排名。

多维区采用细线分隔、纵向内边距（64px）、两列等宽视图及间距（24px），Canvas 宽高比（1.3）。视口不超过（680px）时纵向内边距（40px），视图和结果条纵向排列，控件间距（16px）。英文标题桌面/移动（48px / 36px），中文（36px / 28px），中文行高（1.3）。语言切换保留多维 Worker、所选维度、查询与结果。当前四维核心在打包查询中保留不同对象的独立 ID；完整编号校验独立检查该性质，不从投影外观推断正确性。

## Do's and Don'ts

### Do:

- 保留白色查询/操作语义及实线/虚线审计差异。
- 保留合成数据标签、检查状态、不支持路径和实测失利。
- 保留移动端纵向阅读顺序、表格横向访问，以及滚动区域外的可见标题。
- 保留统一键盘焦点及减少动态效果支持。
- 保留两种完整语言、报告筛选及切换时的实验状态。

### Don't:

- 不把矩形边界审计称为计时遍历遥测，不暗示其他模式有剪枝轨迹。
- 不把浏览器观察值或离线二维快照变成通用、原生或多维性能声明。
- 不用悬浮卡片或胶囊导航替换已实现的平面方形仪器语言。
