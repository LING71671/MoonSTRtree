# 行为规格

[English](../en/SPEC.md) | [中文](SPEC.md)

## 输入与所有权

坐标为 Double，须有限；ID 为非负 Int。构造函数归一化反向区间，支持退化包围盒与重复输入。索引构建后只读，导出与恢复数组复制；调用者临时缓冲可变且必须由单次操作独占。

## 几何

区间闭合，接触边界视为相交。点的每维坐标须介于对应最小/最大值之间。中心先分别折半再相加，避免中点计算溢出。欧氏距离使用运行时开方，不依赖固定轮数的牛顿迭代；平方距离仍受浮点数范围限制。

## 打包

容量最小为 2。二维叶页数为 `ceil(N / M)`，切片数为 `ceil(sqrt(页数))`。先按 X 中心排序，再在切片内按 Y 排序；子节点聚合为父包围盒并逐层重复。三维加入 Z，四维加入时间。排序使用内部副本，不修改调用者数组。固定实现的构建可重现，但查询顺序不属于外部保证。

## 查询与开销

范围/点查询返回全部匹配包围盒 ID，保留重复。空树返回空数组或零计数。计数与过滤结果须和完整查询一致。近邻按点到包围盒最小距离排序，先过滤再接纳，最多返回 k 项。范围查询在高重叠时可退化为 O(N)，结果生成与命中数量成比例。构建排序和临时层级会分配内存。

## 恢复

二维/三维安全恢复拒绝长度错误、负数或溢出邻接范围、越界子索引、环、多父节点、不连通节点、对象数量/树高不匹配、非有限边界、父节点未包围子节点。可信恢复跳过校验，两者成功后都复制输入数组。

## 验收证据

与独立扫描比较完整排序 ID 数组，不能只比命中数量。数值回归覆盖 1e12、1e-12 与整数极值。紧凑 DBSCAN 须保留稀疏和重复 ID。支持目标分别运行测试。性能报告写明工作负载、运行目标、编译器、数据种子、预热、迭代数和原始计时；能力与存储估算不能代替实测。
